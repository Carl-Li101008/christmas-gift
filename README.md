# 圣诞礼物交换所 · Merry & Bright

一个纯前端的圣诞互动小站：无需安装依赖，打开即可玩。

## 运行

```powershell
cd christmas-gift
python -m http.server 8788 --bind 127.0.0.1
```

打开 <http://127.0.0.1:8788/>。

也可以把 `index.html` 拖进浏览器，但「邀请链接 / 贺卡分享链接」在 `file://` 下无法完整工作，建议用上面的本地服务器。

## 内容

- **初入圣诞夜**：从 16 只小动物中领一只，同一段故事里不可重复。
- **礼物工坊**：写一张匿名或署名的贺卡，挑礼物、挑卡面，看圣诞老人乘雪橇送达；贺卡可以拆开、回礼，也可以生成分享链接发给朋友。
- **动物圣诞树**：你的小动物会自动挂上树梢；也可以替访客挑一只。点「摇一摇」会下雪、响铃和落彩带。
- **默契度测试**：主人先写下 6 个答案，把邀请链接发给访客；访客猜答案后得到百分比、默契评语和逐题对照。
- **其他**：圣诞倒计时、许愿雪球、声音开关、分享与本地持久化；页脚可切换「轻量动效」，低配设备上会降低雪景帧率、关闭常驻 CSS 动画。

所有礼物、愿望、小动物与答案都保存在浏览器 `localStorage`，不会上传服务器。分享链接把必要内容编码在 URL hash 中。

## 让其他设备打开

1. 在电脑上运行：
   ```powershell
   python -m http.server 8788 --bind 0.0.0.0
   ```
2. 用 `ipconfig` 找到本机 Wi-Fi 的 IPv4 地址，例如 `192.168.1.23`。
3. 同一 Wi-Fi 下的手机 / 平板打开 `http://192.168.1.23:8788/`。
   如果打不开，通常是 Windows 防火墙拦截了 Python 的入站连接，需要允许 Python 通过专用网络。
4. 不在同一网络时，可用 SSH 反向隧道临时公开（例如 `ssh -R 80:localhost:8788 nokey@localhost.run`），终端会输出一个 `https://...` 公网地址；这种免费隧道地址是临时的。
