# 圣诞礼物交换所 · Merry & Bright

一个可以多人一起玩的圣诞互动小站：先看看今晚的公共圣诞树，再决定要不要领一只小动物。

**在线访问：** <https://carl-li101008.github.io/christmas-gift/>

**管理台：** <https://carl-li101008.github.io/christmas-gift/admin.html>（口令由搭建者保管）

GitHub 仓库：<https://github.com/Carl-Li101008/christmas-gift>

## 运行

```powershell
cd christmas-gift
python -m http.server 8788 --bind 127.0.0.1
```

打开 <http://127.0.0.1:8788/>。

也可以把 `index.html` 拖进浏览器，但公共树同步、邀请链接和贺卡分享链接在 `file://` 下无法完整工作，建议用上面的本地服务器。

## 内容

- **公共主页**：不用加入也能先看。主页会实时显示「今晚谁在树上」，每个人的动物和装扮都在上面。
- **形象工坊**：从 16 只小动物和 8 套圣诞装扮中组合出自己的人物；每个「动物 + 装扮」组合只属于一个人，名字也全站唯一。
- **第一次送出礼物才上树**：加入后先挑好形象；真正送出一张贺卡时，才会被记录到公共圣诞树上，送出几份都会累计。
- **动物圣诞树**：所有送出礼物的人共享一棵树。树上的挂饰会实时更新，点开可以看动物、装扮、上树时间和送出的礼物数。
- **默契度测试**：主人先写下 6 个答案，把邀请链接发给访客；访客猜答案后得到百分比、默契评语和逐题对照。
- **管理台**：管理员可以查看全部人物、封禁 / 解封、暂时隐藏 / 恢复、处理举报。被举报的人物会进入待处理列表。
- **其他**：圣诞倒计时、许愿雪球、声音开关、轻量动效开关、贺卡分享与本地持久化。

## 数据说明

- 贺卡文字、愿望、默契答案仍然只保存在浏览器 `localStorage`，不会上传到公共树。
- 名字、动物、装扮、上树时间和送出数量会显示在公共圣诞树上。
- 公共树使用公共 MQTT broker（`broker.emqx.io`）的 retained 消息做轻量实时同步，Topic 写在 `shared.js`。它适合朋友之间的小站，**不是强安全后台**：知道前端代码的人理论上可以直接修改公共状态，管理口令也只是前端校验。请勿在树上放敏感信息。
- 如果公共树所在的 broker 暂时连不上，页面会先用本地缓存的快照；恢复连接后自动同步。

## 让其他设备打开

线上版本直接打开上面的 GitHub Pages 地址即可。若要在本机测试：

1. 在电脑上运行：
   ```powershell
   python -m http.server 8788 --bind 0.0.0.0
   ```
2. 用 `ipconfig` 找到本机 Wi-Fi 的 IPv4 地址，例如 `192.168.1.23`。
3. 同一 Wi-Fi 下的手机 / 平板打开 `http://192.168.1.23:8788/`。
   如果打不开，通常是 Windows 防火墙拦截了 Python 的入站连接，需要允许 Python 通过专用网络。

## 管理员口令

管理员口令只以 SHA-256 哈希保存在 `admin.js` 中。需要修改时，把新口令的 SHA-256 替换 `ADMIN_HASH` 即可。管理台只适合朋友间维护，不要当作真正的权限系统。
